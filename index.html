PS4 — In-Browser WebKit Chains

Open this page in the PS4 web browser. The host detects your firmware, loads the matching WebKit + kernel chain, then injects GoldHEN — all cached on the console so re-loads are instant.

Chain Stage

Stage 1 — WebKit userland: idle
Stage 2 — Kernel exploit: idle
Stage 3 — GoldHEN payload: idle
Stage 4 — Cache & persist: idle

What happens

  1. Detect firmware from the browser user agent
  2. Load the correct exploit chain for that firmware
  3. Run WebKit userland + kernel stage
  4. Inject latest GoldHEN payload (no USB needed)
  5. Payload + exploit files are cached on the device
Tethered: after a full power-cycle you must re-run the jailbreak. Caching only removes the downloads, not the re-trigger — that is a kernel/platform reality on every public chain.

PS5 — Y2JB + P2JB (WebKit via YouTube)

The PS5 has no browseable browser, so its WebKit jailbreak runs inside the modded YouTube app (Y2JB framework). This host serves as your LAN payload server and controller.

LAN Server

Run the included server on a PC connected to the same network, then push p2jb.js / elfldr to the PS5’s Y2JB listener.

node tools/serve.js  or  powershell -File tools/serve.ps1

Y2JB Workflow

  1. Restore the Y2JB system backup (Gezine/Y2JB) on your PS5
  2. Install the matching YouTube app version for your firmware
  3. Launch YouTube → load Y2JB (WebKit userland)
  4. Push P2JB kernel payload from this host (may take 10–50 min — patience!)
  5. aioSD / etaHEN / GoldHEN for PS5 via kstuff
Firmware 13.00+ (13.20 / 13.40): Y2JB userland works but no public kernel exploit exists yet. Stay on your current firmware — do NOT update.
